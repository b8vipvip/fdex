# FDEX v1.1.38

Production release of the current accepted mainline after v1.1.37.

## Included

- Codex Provider Rollout now renders smoke timestamps in Beijing time (`Asia/Shanghai`) while preserving UTC persistence for compatibility-age calculations.
- Carries all Codex Provider smoke, rollout progress, runtime diagnostics, logging/export and Coding Agent fixes merged since v1.1.37.
- Intended to align with chat2api v0.22.71 for the latest FDEX full-smoke Responses / Worker fixes.

## Release path

This PR is release-only and intentionally introduces no new runtime behavior. The merge commit must contain `[release]`. After merged-main `Build and Test` succeeds, `auto-tag-release.yml` will:

1. resolve the next patch tag (`v1.1.38`);
2. tag the merged main SHA;
3. validate Android signing secrets;
4. build the signed `fdex-1.1.38.apk`;
5. publish the GitHub Release with the APK asset.
