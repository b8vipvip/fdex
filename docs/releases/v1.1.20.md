# FDEX v1.1.20

本版本重构 Android 客户端“我的”与设置中心，移除串页和空占位，让账号、隐私安全、客户端设置、版本更新和帮助支持各自承担真实职责。

## 账号信息

- 账号页不再混放公司行业、专业程度等客户端/业务配置。
- 显示当前登录账号与登录方式。
- 支持维护姓名/昵称与手机号。
- 显示当前邮箱；由于邮箱同时是本机登录标识，本版本在资料页保持只读，避免仅修改资料却造成登录凭据不一致。

## 隐私与安全

- 新增“自动整理聊天到本机知识库”隐私开关。关闭后不再自动历史回填，也不再把新的私聊、群聊、Realtime 文字交换自动生成知识条目；已有知识仍可手动浏览与检索。
- 新增“MemPalace / Letta 长期记忆”隐私开关。关闭后客户端不再生成或发送 FDEX_MEMORY_V2 控制信息，普通聊天与 Realtime 均停止跨会话远程召回/写入。
- 新增真实密码修改：必须验证当前密码，新密码至少 8 位且两次输入一致；继续使用现有 PBKDF2 + Android Keystore 设备密钥凭据格式，不保存明文密码。
- 页面明确说明本机聊天/知识库、远程长期记忆以及 Realtime 纯文本记忆的数据边界。

## 客户端设置

- 公司名称、公司行业、默认专业程度、默认自动运营从账号资料页迁入设置。
- 新增默认打开页面：消息 / 知识库 / 发现 / 我的；已登录冷启动、登录成功和注册完成后都会实际生效。
- 新增“显示 AI 思考摘要”开关，只控制流式 reasoning UI 展示，不影响答案生成。
- 新增“回答时自动滚动到底部”开关，直接控制员工私聊和群聊流式页面自动跟随。
- 新增“自动检查新版本”开关；启用后保持启动时最多每 6 小时检查一次，关闭后仍可手动检查。

## 检查更新 / 关于 FDEX

- 新增独立“检查更新”入口，承接原关于 FDEX 页面。
- 展示版本名称、版本号、构建提交、服务端地址、服务状态、更新来源与上次检查时间。
- 保留应用内手动检查与签名 APK 更新流程。

## 帮助与支持

- “使用说明”改为真实使用指南，覆盖员工管理、私聊/群聊、知识库、Realtime 实时语音与 request_id 诊断。
- “隐私说明”按当前实际实现说明账号密码、本机数据、MemPalace/Letta、AI 路由和 Realtime 数据边界。
- “联系我们”提供 GitHub Issues 正式反馈入口，并提示仅提交脱敏日志，不提交密码/API Key/密钥。
- 不再让“隐私与安全”“使用说明”“隐私说明”“联系我们”等入口复用同一个设置或关于页面。
