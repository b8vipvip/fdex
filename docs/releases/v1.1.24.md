# FDEX v1.1.24

本版本增强 Android 客户端聊天交互、员工当前会话上下文理解，以及员工权限编辑保存体验。

## 聊天消息操作

- 私聊和工作群中的历史消息下方新增“复制 / 删除 / 引用”按钮。
- 复制只复制用户可见正文，不把 FDEX 附件内部 marker 写入剪贴板。
- 删除按消息 ID 从本地 SQLite 会话记录中移除；后续当前线程上下文也不会再带入已删除消息。
- 引用会把目标消息以 blockquote 写入输入框，并保留用户已经输入的草稿；旧附件只显示“包含附件”提示，不重复携带旧附件 URI/Base64。

## 当前会话历史联想

- 员工普通聊天新增独立的“当前线程近期上下文”层。
- 最近最多 24 条、约 9000 字符的当前会话消息按真实时间顺序加入主 AI 请求，用于理解连续追问、省略主语、指代、对上一轮的修正等。
- 当前正在发送的用户消息从历史窗口排除，避免同一内容重复出现。
- 当前线程近期消息优先服务于本轮对话；更老信息继续交给现有 Knowledge / MemPalace / Letta 长期记忆召回。
- 不新增摘要模型、RECALL_ONLY 或任何额外生成请求，不与主员工回答争抢模型线路。
- 历史消息明确作为会话数据而非系统指令；若历史与本轮用户明确陈述冲突，以本轮用户陈述为准。
- 工作群同样保留成员名称和消息顺序，让目标员工理解群内前后文。

## 员工权限编辑

- 编辑已有员工时，即使该员工 Prompt 为空，也可以只修改“知识库读写 / 聊天记录读取范围”等权限并保存。
- 新建员工仍保持原有完整性校验：名称、部门、职位和 Prompt 需要填写完整。
- AI 正在生成员工 Prompt 时仍禁止保存，避免并发覆盖。

## 验证

- PR #44：FastAPI Tests 通过。
- Android unit tests 通过。
- Android Debug APK 构建通过。
- 新增当前会话顺序、排除本轮消息、预算截断、群成员名称、附件引用清理和权限单独保存回归测试。

本版本为 Android 客户端与本地 SQLite 行为更新，不要求 FDEX 服务端或 chat2api 服务端额外升级。
