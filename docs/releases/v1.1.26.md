# FDEX v1.1.26

本版本为 Android 客户端聊天消息增加系统原生长按文本选择能力，支持在单条消息内自由选择并复制任意文字，同时保持现有消息操作、附件和会话逻辑不变。

## 原生文本选择

- 私聊用户消息与 AI 员工回复正文加入 Jetpack Compose 原生 `SelectionContainer`。
- 工作群用户消息、AI 员工消息和系统文本消息均支持长按选择。
- 长按消息文字后使用 Android / Compose 原生文本选择工具栏与选择手柄，可复制、全选并拖动起止手柄自由调整选择范围。
- SelectionContainer 只作用于单条消息正文，不包裹消息下方复制、引用、删除图标，避免操作栏进入文本选择范围。

## Markdown 与附件

- 单条 AI Markdown 回复使用一个消息级选择边界，标题、段落、列表、引用、代码和表格等多个文本 block 可在同一回复范围内进行选择。
- Markdown 链接、媒体卡片与附件卡片继续保留原有点击行为。
- 用户附件消息继续通过 `parseChatContent()` 只显示实际正文与附件卡片；内部 `FDEX_ATTACHMENTS_V1` marker、URI/Base64 数据不会作为正文暴露。
- AI 富媒体回复继续通过 `parseRichAssistantContent()` 移除内部媒体 marker 后再渲染可见 Markdown。

## 兼容性与回归保护

- 保留消息下方复制、引用、删除三个图标及原有点击行为。
- 不修改私聊或群聊软删除机制；`deleted=true` 消息仍从列表和近期会话上下文排除，并继续保留现有最近删除/恢复能力。
- 不修改当前会话历史联想的 24 条 / 9000 字符规则。
- 不增加任何 AI 请求，也不修改 Knowledge、MemPalace、Letta、AI provider、realtime 会话协议或 chat2api 调用逻辑。

## 验证

- PR #46 FastAPI Tests 通过。
- Android unit tests 通过。
- Android Debug APK 构建通过。
- 新增 JVM 结构回归测试，验证私聊和群聊正文的原生 selection 边界、操作栏隔离，以及附件/AI 内部 marker 不直接进入可选择正文。

本版本仅为 Android 客户端 UI 增强，不要求 FDEX 服务端或 chat2api 服务端升级。
