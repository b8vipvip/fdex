# FDEX v1.1.25

本版本修复 v1.1.24 单条聊天消息删除未按预期生效的问题，并重新设计消息下方操作按钮样式。

## 单条消息删除

- 私聊单条删除不再直接物理删除 SQLite 行，改为与 FDEX 既有“清空聊天 / 最近删除”一致的 `deleted=true` 软删除机制。
- 点击删除后，该消息立即从当前私聊列表过滤，同时继续保留在“最近删除”体系中，可沿用现有恢复能力。
- SQLite 增加按消息类型和消息 ID 精确读取，删除操作先定位目标记录再回写 deleted 状态。
- 工作群消息新增兼容字段 `deleted=false`；旧数据没有该字段时自动按未删除处理，不需要数据库版本迁移。
- 群聊消息删除后会从群聊列表以及消息页最近预览中同步消失。
- 私聊和群聊的近期会话上下文都会排除 deleted 消息，避免界面上删除后员工在后续连续对话中仍引用已删除内容。

## 消息操作图标

- 原“复制 / 删除 / 引用”文字按钮改为纯图标按钮，减少消息下方占用空间。
- 复制：灰蓝色复制图标，作为低干扰常用操作。
- 引用：蓝色引用图标，突出继续对话操作。
- 删除：红色删除图标，并放在操作区最右侧，明确危险操作属性。
- 所有图标保留无障碍 contentDescription，不依赖文字按钮也能表达操作含义。

## 验证

- PR #45 FastAPI Tests 通过。
- Android unit tests 通过。
- Android Debug APK 构建通过。
- 新增回归测试确认私聊和群聊 deleted 消息都不会进入员工当前会话历史联想。

本版本为 Android 客户端与本地 SQLite 行为更新，不要求 FDEX 服务端或 chat2api 服务端额外升级。
