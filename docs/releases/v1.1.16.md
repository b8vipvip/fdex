# FDEX v1.1.16

本版本集中修复此前确认的 4 项技术债，并作为 v1.1.15 之后的稳定性升级正式发布。

## 主要更新

### 视频与普通文件真实内容理解

- 视频附件在 Android 本机抽取最多 4 个代表画面，并送入现有视觉模型分析。
- PDF、DOCX、XLSX/XLSM、PPTX 及常见文本、代码、配置文件支持读取真实正文。
- 文档正文仅在 FDEX 服务端内存中提取并加入当前 AI 请求，不持久化原始文档正文。
- 不支持、不可读取或未提取到文字的附件会明确标记为未读取，避免根据文件名或元信息猜测内容。
- 工作详情中的资料分析改为使用真实附件内容，而不是仅依赖文件名、MIME 和文件大小。

### README 与正式发布链路同步

- 文档已同步当前实际发布方式：`main` 上带 `[release]` 的提交在 CI 通过后自动生成下一个 patch 版本。
- 正式 APK 使用仓库既有固定 Android 签名证书构建。
- GitHub Release 和 APK 上传由自动发布工作流完成。
- 手工 tag 发布继续作为备用流程。
- Android 更新继续使用 `latest_only` 策略。

### 本地账号凭据安全升级

- 新账号密码改为随机盐 + PBKDF2-HMAC-SHA256（210,000 次）派生。
- 密码派生结果再由 Android Keystore 中不可导出的设备 HMAC 密钥保护。
- 旧版 SHA-256 凭据保持兼容；旧用户第一次成功登录后自动升级到新凭据格式，不要求重置密码。

### SharedPreferences 业务数据迁移到 SQLite

- 新增 `fdex-local-v3.db`。
- 员工、聊天消息、工作、笔记、资料索引、报告、工作群和群消息迁移为 SQLite 按实体存储。
- 首次升级时从旧 `fdex_app_v2` JSON 数据自动事务迁移。
- 只有 SQLite 提交成功后才删除旧业务数组，保留旧数据、ID、Prompt 和附件 URI。
- 账号/session/profile 等小型状态继续保留在 SharedPreferences。

## 兼容性说明

- 不改变员工 `rolePrompt` 完全由 Android 客户端管理并原样透传的原则。
- 第三方 AI API Key 仍只保存在 FDEX 服务端。
- Realtime 通话中的文字仍固定走当前实时会话，不回退普通 AI Provider。
- 视频当前实现为代表画面视觉分析，不包含视频音轨转写。
- 扫描版纯图片 PDF 当前不执行 OCR；若无可提取文字，会明确提示未读取正文。
