# FDEX v1.1.22

本版本修复图片+文字聊天在浏览器附件准备/视觉首包较慢时被客户端过早断开的情况，并包含服务端流式记忆中间件高 CPU 忙循环热修复。

## 图片与附件流

- Android 非音频附件流的 read timeout 从 30 秒调整为 120 秒，覆盖浏览器桥附件上传确认、模型准备和视觉首包窗口。
- 普通文本流仍保持原有 90 秒读取超时，不把所有聊天都放宽成长等待。
- FDEX 继续通过 SSE status/done/error 事件管理请求生命周期，120 秒仅是网络 idle budget，不代表固定等待 120 秒。
- 与 chat2api 的 SSE keepalive 修复配套：浏览器侧长时间准备附件时保持上游 HTTP 流活跃，避免中间层误判死连接。

## 服务端流式稳定性

- 修复 FDEX Memory Middleware 重写请求后重复立即返回空 `http.request`，导致 Starlette StreamingResponse disconnect listener 高速自旋的问题。
- 重写请求体只 replay 一次，后续 ASGI receive 等待真实客户端事件，避免单个流式请求拉满 Python worker CPU、拖慢管理后台并最终超时。
