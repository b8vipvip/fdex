# Phase 7.13 · 智体模型

FDEX 的用户模型从“公司 / AI 员工”调整为通用“智体”。

用户创建智体时只需要填写 **身份定义提示词**，该字段允许留空。系统自动分配 `智体 1`、`智体 2` 等显示名称，创建后可以修改显示名称、身份提示词、知识/聊天权限以及是否启用 Coding Agent。

为避免破坏既有用户数据、聊天历史、长期记忆 ACL、工作群成员 ID、Coding Agent 偏好和旧客户端协议，内部数据库记录类型、部分 Kotlin 类型和兼容 URL 暂时继续使用历史名称 `employee` / `Employee`。这些内部标识不再代表公司雇佣关系，也不再作为用户界面术语。

旧版 `company_name`、`industry`、`department`、`position` 等数据在新的 Web / Android 运行时会被清空或忽略；新数据不再采集这些字段。中央认证协议保留空的 `company_name` 兼容字段，避免旧客户端解析失败。
