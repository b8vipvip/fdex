权限模型

GitHub App Installation 是唯一 GitHub 权限源。Coding Agent 对每次具体操作仍会生成“当前仓库 + 当前操作”的短期 installation token：读取仓库只申请 Contents read，Push 时申请 Contents write，创建 PR 时申请 Pull requests write。FDEX 不把一个全仓库长期 Token 交给 Agent。

Remote MCP 安全网关

当前 FDEX 账号独立配置。Phase 7.26 已支持匿名 HTTPS Streamable HTTP MCP，通过 FDEX 本地网关接入 Codex。

{{ remote_mcp_servers|length }}
安全边界：Codex 不会直接连接你填写的远端 URL。每个新任务只拿到一个 127.0.0.1 临时 capability；FDEX 在每次远端请求前重新解析 DNS，要求全部地址为公网 IP，并把该次连接固定到已验证地址，同时继续按原域名验证 TLS SNI/证书。3xx 重定向和 401/403/407 认证挑战不会透传。本阶段仍不保存 bearer token、OAuth token、任意远端 HTTP Header，也不开放本地 stdio command/args/env/cwd。

临时 capability 原文不落库，只保存 SHA-256；capability 放在本机请求 Header 中，不进入 URL、普通访问日志或 Codex shell 环境。任何编辑、停用、重新启用都会改变注册项版本并立即让旧 task lease 失效。

每行或逗号分隔一个工具名。启用前必须至少配置一个 allowlist；Codex 配置和 FDEX 网关都会执行这份白名单，空列表永远不表示“全部工具”。
