权限模型

GitHub App Installation 是唯一 GitHub 权限源。Coding Agent 对每次具体操作仍会生成“当前仓库 + 当前操作”的短期 installation token：读取仓库只申请 Contents read，Push 时申请 Contents write，创建 PR 时申请 Pull requests write。FDEX 不把一个全仓库长期 Token 交给 Agent。

Remote MCP 安全网关

支持匿名、FDEX-held 静态 Bearer，以及 OAuth 2.0 Authorization Code + PKCE；远端长期凭据始终留在 FDEX。

{{ remote_mcp_servers|length }}
安全边界：Codex 只连接 127.0.0.1 的任务临时 capability，不直接拿到远端 URL、Bearer、OAuth access/refresh token 或 client secret。FDEX 每次 MCP 请求重新验证公网 DNS、固定连接 IP、按原域名验证 TLS；OAuth token/refresh/revoke 请求也使用同样的 HTTPS 443 + 公网 DNS + pinned connection + 禁止重定向策略。

静态 Bearer 轮换会改变 credential revision。OAuth access token 自动刷新只更新同一 grant 的短期 token，不改变 grant revision；重新授权或撤销 OAuth grant 才会立即使旧 task lease 失效。
