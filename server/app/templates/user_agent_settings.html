权限模型

GitHub App Installation 是唯一 GitHub 权限源。Coding Agent 对每次具体操作仍会生成“当前仓库 + 当前操作”的短期 installation token：读取仓库只申请 Contents read，Push 时申请 Contents write，创建 PR 时申请 Pull requests write。FDEX 不把一个全仓库长期 Token 交给 Agent。

Remote MCP 安全网关

Phase 7.27 支持匿名或静态 Bearer 的 HTTPS Streamable HTTP MCP；远端凭据始终由 FDEX 持有，不交给 Codex。

{{ remote_mcp_servers|length }}
安全边界：Codex 只连接 127.0.0.1 的任务临时 capability，不直接拿到远端 URL 或 Bearer。FDEX 每次请求重新验证公网 DNS、固定实际连接 IP、按原域名验证 TLS，并在这些检查和 owner/server/lease 版本校验全部通过后，才从加密 vault 解密并注入 Authorization: Bearer …。3xx 不跟随，认证挑战不透传，仍不开放任意远端 Header、OAuth 或本地 stdio command/args/env/cwd。

Bearer 使用 FDEX 独立 Fernet vault 加密保存；页面只显示是否配置和不可逆短指纹，从不回显 token。新增、轮换或删除 Bearer 都会立即使旧 task lease 失效，新凭据只能由后续新任务 / resume / fork 使用。
