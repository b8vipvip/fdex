维护说明

操作边界与安全策略

  • 网页更新只能执行固定路径 {{ settings.app_dir }}/scripts/update_server.sh，不能提交任意 Shell 命令。
  • 目标端口被其他服务占用时，更新脚本只会报错退出，不会结束其他进程。
  • server/.env 在更新前自动备份并恢复，第三方 API Key 不会提交到 GitHub。
  • 更新进度写入本机 server/data/admin-update-status.json，并结合 systemd journal 显示最近日志；服务重启后仍可恢复显示。
  • 实时语音诊断下载仅对已登录管理员开放，诊断目录不会作为公开静态目录暴露。
  • 所有重启、更新和诊断下载操作都会记录管理员、IP、时间和执行结果。
