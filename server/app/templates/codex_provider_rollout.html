Failover 语义

Provider failover 只发生在官方 Codex Host 启动前。

允许

任务 Host 启动前，按优先级跳过没有 fresh full 证明的 Provider，选择下一个已验证 Provider。

禁止

一旦官方 Codex Host/Turn 已开始，Provider 请求失败就让该任务失败；不会在同一 worktree 中自动切到另一个 Provider。

恢复

用户 Retry 会创建新的 FDEX task。Provider 重新选择发生在新的执行边界。

Codex-only

没有可用的 fresh full-compatible Provider 或 Runtime 时直接失败；不会转交 Legacy Agent、通用 AI 或其他执行核心。
