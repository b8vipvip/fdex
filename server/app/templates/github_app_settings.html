权限边界

GitHub 负责第一层仓库选择，FDEX 再负责第二层 Coding Agent 项目权限。

  • Contents：read/write（安装层最大权限；实际 Clone/Fetch/Push 时会再下缩）
  • Pull requests：read/write（只有 FDEX 项目明确允许创建 PR 才会使用）
  • Metadata：read
  • 用户 Token 只在短暂安装身份校验阶段使用，完成后清除；安装 Token 每次操作临时生成，不落库。
