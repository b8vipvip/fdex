授权边界

FDEX 平台只配置一次 GitHub OAuth 应用身份。每个用户都必须使用自己的 FDEX 账号登录本页面并亲自完成 GitHub 授权；管理员后台不能替用户选择 GitHub 身份。用户的 GitHub 凭据按 FDEX user_id 加密隔离，浏览器和 Android 客户端都不会接收到明文令牌。
