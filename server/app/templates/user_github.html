统一权限模型

仓库访问和 GitHub 权限不再按仓库重复配置；沙箱运行策略按 FDEX 账号统一配置一次。

Coding Agent 运行策略

GitHub 仓库范围：完全由 GitHub App 的“全部仓库 / 仅指定仓库”决定。读取、Push、PR：完全继承 GitHub App permissions。构建联网、内存、CPU：在 FDEX 的账号级运行策略中统一设置。

FDEX 内部仍保留 project_id 作为稳定工作区和任务历史索引，但它不再是用户需要手工维护的权限对象。仓库从 GitHub App 范围移除后会停止接受新任务；重新加入后会自动恢复。

最小权限执行

即使 GitHub App 安装覆盖多个仓库，某个 Coding Agent 任务也不会拿到一个“全仓库长期 Token”。Clone/Fetch 时生成只限制当前仓库的 Contents read 短期凭据；Push 时生成当前仓库的 Contents write；创建 PR 时生成当前仓库的 Pull requests write。
