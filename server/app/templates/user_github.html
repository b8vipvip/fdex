Phase 7.7 授权边界

平台只配置一次 FDEX GitHub App 身份。每个 FDEX 用户必须亲自在 GitHub 官方安装页选择账号/组织和仓库范围；FDEX 长期只保留 installation_id 与非密钥安装元数据，不长期保存用户 OAuth access token，也不保存 installation token。执行 Clone/Fetch 时生成仅当前仓库的只读短期凭据；Push 与 PR 再分别按当前项目权限生成更小权限的短期凭据。
