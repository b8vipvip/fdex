隔离与权限边界

account → project → task 三层文件隔离 + 一次性执行沙箱

账号 / 项目隔离

不同账号使用不同 owner 目录和 GitHub 凭据；不同项目不共用 repository/worktree。任务只能修改自己的 worktree。

执行隔离

配置项目的测试/编译通过 systemd transient unit 运行，限制内存、CPU、PID、设备和宿主文件系统；网络默认关闭，可按项目显式开启。

GitHub 写权限

默认关闭。只有项目显式允许后，Agent 才能 push 自己生成的 fdex-agent/* 分支并创建 PR；不能直接修改 main。

无常驻容器

账号空闲时没有独立 Agent 容器/JVM/Gradle daemon 常驻，因此账号数量增加不会线性占用内存。
