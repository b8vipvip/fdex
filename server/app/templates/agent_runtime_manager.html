校验链

Runtime 进入激活状态前必须依次通过全部检查。

1. 固定来源

只访问 GitHub API 的 repos/openai/codex/releases，资产 URL 必须精确落在对应官方 tag。

2. 资产完整性

要求 GitHub release asset 提供 sha256: digest；下载长度与 digest 必须完全一致。

3. 安全解包

不调用 extractall；拒绝绝对路径、..、symlink、hardlink、device，只复制唯一预期可执行文件。

4. 协议能力

验证 --version，再用当前 FDEX Multi-Agent/Rollout 配置执行 app-server --help，防止版本能运行但协议配置不兼容。

5. 进程代际切换

切换 pin 前结束所有 fdex-codex-*.service cgroup；旧 Runtime 不允许跨版本继续存活。
