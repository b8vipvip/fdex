GitHub 出站测试

验证真实 GitHub 功能路径和本地代理认证隔离。

测试不再把任意 HTTP 响应当成成功：github.com 必须返回正常 2xx/3xx，api.github.com 必须返回 HTTP 200。HTTP 403 rate limit 与 406 都会明确显示为异常。

若 api.github.com 返回 403 rate limit，说明网络通常已经到达 GitHub，但 API 配额不可用，不能算功能测试通过。配置 GITHUB_TOKEN 后，本测试和版本维护请求会优先使用服务端 Token 配额。

工作原理

服务器其它服务不会被代理。

当前启用 VLESS 节点 → FDEX 专用 HTTP 代理 → 独立 Xray → VLESS VPS → GitHub
FDEX GitHub API / OAuth / Installation Token 与 Coding Agent git clone / fetch / push → 同一 FDEX 专用出口
AI Provider / SMTP / Letta / Qdrant / 服务器其它服务 → 原有服务器网络（不经过该 VLESS）
