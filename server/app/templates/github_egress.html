工作原理

服务器其它服务不会被代理。

FDEX GitHub API / OAuth / Installation Token → FDEX 专用 HTTP 代理 → Xray VLESS → 美国 VPS → GitHub
Coding Agent git clone / fetch / push → Git 子进程专用 GitHub proxy → 同一 Xray VLESS → GitHub
AI Provider / SMTP / Letta / Qdrant / 服务器其它服务 → 原有服务器网络（不经过该 VLESS）
